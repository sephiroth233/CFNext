# CFNext

CFNext 是部署在 Cloudflare Workers / Pages 上的单文件代理与订阅管理面板，用于集中管理节点、优选地址和客户端订阅。当前版本：**2.0.5**。

## 功能

- 支持 VLESS WebSocket 和 VLESS XHTTP。
- 仅生成 UTF-8 明文 VLESS 订阅（每行一个 `vless://` 链接），支持预览、复制、二维码和下载。
- 管理优选 IP、域名来源、节点筛选与数量上限。
- 支持 SOCKS5、HTTP/HTTPS CONNECT 和 Shadowsocks 出站代理。
- 通过 Cloudflare KV 保存配置，支持配置导入与导出。
- 默认跟随系统主题，也可手动选择浅色或深色模式。

## 部署

仓库主脚本为 `workers.js`，无需安装项目依赖或构建。

### Cloudflare Pages

1. 创建 Pages 项目，选择直接上传。
2. 将 `workers.js` 复制为 `_worker.js`，放在上传目录或 ZIP 文件的根目录。
3. 在项目设置中配置下方的环境变量，并绑定 KV 命名空间 `K`。
4. 上传并部署；修改环境变量或绑定后，重新部署使其生效。

### Cloudflare Workers

1. 创建模块 Worker，将 `workers.js` 作为入口脚本。
2. 配置环境变量和 KV 绑定 `K`。
3. 保存并部署，使用分配的域名或已绑定的自定义域名访问。

## 配置

首次部署时，必须分别配置代理 UUID `U` 和管理面板路径 `D`；使用管理面板还需配置 `ADMIN`，保存设置需绑定 `K`。管理面板路径没有默认值，不能使用 UUID。若环境变量和 KV 中均未配置管理密码，管理入口会关闭；在 UUID 和管理面板路径均有效的前提下，代理与令牌订阅仍可使用。密码、令牌和代理凭据建议保存为 Cloudflare Secret。

### 基础配置

| 名称 | 说明 |
| --- | --- |
| `U` | 代理 UUID，填写有效的 UUID |
| `ADMIN` | 面板管理密码，建议使用至少 12 位随机密码；保存面板配置时要求至少 8 个字符，详见下方校验说明 |
| `K` | KV 命名空间绑定名称，用于持久化面板配置 |
| `D` | 必填，独立的管理面板路径，必须与 UUID 不同；例如 `panel` 对应 `/panel`，填写规则见下方路径限制 |
| `HOST` | 可选，订阅节点的 SNI/Host；默认使用当前访问域名 |
| `SUB_TOKEN` | 可选，独立订阅令牌，32–128 位字母、数字、下划线或连字符；未设置时由 UUID 派生 |
| `S` | 可选，出站代理地址，支持 `socks5://`、`http://`、`https://`、`ss://`；省略协议时按 SOCKS5 解析 |
| `PROXYIP` | 可选，自定义透明中继地址，可带端口 |

**配置优先级为：默认值 < KV 保存值 < 显式环境变量。** 未绑定 KV 时，面板无法保存修改。`HOST` 只设置节点参数，自定义域名仍需在 Cloudflare 项目中绑定。

当前脚本还兼容 `PATH`（对应 `D`）、`OUTBOUND`（对应 `S`）和小写 `admin`（对应 `ADMIN`）。同一配置同时设置两个非空变量时，分别以 `PATH`、`OUTBOUND`、`admin` 为准；建议每项只设置一个变量，避免覆盖混淆。

**密码校验说明：** 当前版本加载环境变量和登录时不校验密码的最低长度，保存面板配置时才检查至少 8 个字符。因此，过短的 `ADMIN` 会出现“可以登录，但保存普通设置也失败”的情况。遇到此情况，请先在部署设置中更新 `ADMIN` 并重新部署，再登录保存。

**路径限制：** 管理面板路径必须显式配置，可来自 `D`（兼容 `PATH`）或 KV 中已保存的 `path`，不再回退到 UUID。缺失、留空或与 UUID 相同均会返回 400；已有部署若尚未设置独立路径，需先补充 `D` 并重新部署。订阅别名 `subUrl` 仍为可选。面板路径和非空订阅别名规范化后必须是 1–128 个字符的单一路径段，只能包含字母、数字、下划线、连字符、点和波浪号，不能使用保留值 `s`、`login`、`version`、`favicon.ico`。例如 `D=panel` 对应 `/panel`；`D=admin/panel` 和 `D=login` 均无效，会使登录等需要加载配置的请求返回 400。`D` 不改变代理入口 `/<UUID>`。

### 可选环境变量

下列选项可在管理面板中设置，也可通过环境变量覆盖：

| 名称 | 说明 |
| --- | --- |
| `ECH` | 设为 `true` 或 `1` 开启 ECH；显式设置其他值时关闭 |
| `ALPN` | 自定义节点 ALPN 参数，例如 `h2,http/1.1` |
| `YX` | 自定义优选 IP 列表，格式如 `104.16.128.11:443#节点名称`，多项用逗号分隔 |
| `YXURL` | 优选器自定义候选数据源 URL |
| `PROBE_ALIVE` | 设为 `true` 或 `1` 开启节点测活；显式设置其他值时关闭。Worker 侧探测结果不等同于客户端可达性 |
| `CF_ACCOUNT_ID` | Cloudflare 用量监控的账户 ID，与 API 令牌配合使用 |
| `CF_API_TOKEN` | 用量监控 API 令牌，需具备账户用量分析读取权限 |

以下选项仅通过环境变量配置，管理面板没有对应的设置项：

| 名称 | 说明 |
| --- | --- |
| `SESSION_SECRET` | 可选，会话签名密钥；默认使用管理密码。更换密钥后需重新登录 |
| `UPDATE_REPO` | 更新检查来源，格式为 `owner/repo`；未设置时更新检查关闭 |
| `UPDATE_BRANCH` | 更新来源分支，默认 `main`，需配合 `UPDATE_REPO` |
| `UPDATE_FILE` | 更新来源仓库中的脚本路径，默认 `workers.js`，需配合 `UPDATE_REPO` |
| `RELAY_EXIT_PROBE` | 设为 `0` 或 `false` 关闭节点名称中的地点后缀；默认保留。此变量沿用旧名称，当前不用于探测真实出口 |

## 使用

1. 访问 `https://你的域名/login`，使用 `ADMIN` 密码登录。未登录访问根路径返回 404 属于正常行为。
2. 在面板中设置协议、优选地址和筛选条件，点击「保存全部」。
3. 回到仪表盘，复制明文 VLESS 订阅链接并导入支持此格式的客户端。
4. 在客户端更新订阅并测试节点，按实际网络情况选择使用。

默认订阅地址为 `/s/<订阅令牌>/sub`，具体链接直接从面板复制。订阅包含连接凭据，请勿公开分享。订阅只包含已启用的 VLESS WebSocket / VLESS XHTTP 节点，不包含分流规则，也不按客户端或 User-Agent 转换格式。

## 使用说明

- 节点的 WebSocket / XHTTP 代理路径固定为 `/<U 的值>`，与 `D`（管理面板路径）独立。升级后请更新客户端订阅，旧版使用 D 路径的节点需重新导入。
- 当前仅支持 TCP 转发，客户端 DNS 建议使用本地解析或 DoH。
- 配置保存后，不同地区可能因 KV 缓存而稍后生效。
- 配置导出不含管理密码、出站凭据等敏感字段，但仍包含 UUID 和管理路径；迁移时需重新设置未导出的凭据。
- 已登录管理面板会显示当前出站代理地址（包括其中的凭据）；清除按钮需点击「保存全部」后才生效。
- 默认出站模式先尝试代理，TCP 连接和代理握手合计最多等待 2 秒；失败后走与未配置代理时相同的路径：自定义落地（如有）→ 直连目标 → 内置地区反代。兜底另有 15 秒、最多 4 次连接的预算，解析中继地址也计入时间预算。
- 代理端点连接失败时，同一 Worker 运行实例内的后续请求会暂避该代理 30 秒；修改代理地址或凭据后立即重新尝试。单个目标的 SOCKS5 CONNECT 失败不会停用整个代理。「仅走代理」不启用直连兜底。切换发生在连接建立阶段，已开始转发的连接中途断开时需由客户端重连。
- 自定义订阅地区优先识别备注中的独立国家/地区码（如 `| HK |`），其次识别旗帜、已知机房码和标准地区名称，兼容 bestcf 天诚源的昵称备注；地区筛选使用解析后的元数据。只有国家码时仅追加地区后缀，有匹配的机房码时才追加城市。来源标签不代表实测出口，也不固定出口 IP。
- 地区不明的通用节点仍沿用原有兜底规则；筛选无结果时会逐级放宽条件。
- 明文订阅最多 800 条节点；开启数量控制时再与配置上限取较小值，默认上限为 300。WebSocket / XHTTP 节点共同计数，实际数量取决于来源和筛选结果。
- 轮询换新默认关闭；开启后按配置版本、15 分钟时间窗口和客户端 User-Agent 轮换候选顺序，不向 KV 记录已下发 IP，也不保证相邻窗口完全不重复。
- 当前未启用定时自动优选。脚本保留的 `scheduled` 入口仅记录停用日志，不会测速或写入优选节点。
- 节点可用性取决于客户端网络、数据来源与出站服务；面板测速仅供参考。
- 部署和运行受 Cloudflare 套餐限制，用量以 Cloudflare 控制台为准。

## 本地检查

使用 Node.js 运行订阅回归测试（已在 Node.js 24.19.0 验证，无需安装依赖）：

```sh
node --test tests/subscription.test.mjs
```

回归测试覆盖独立面板路径校验、明文订阅、WS/XHTTP、旧配置清理、路由鉴权和面板订阅操作等行为。测试在隔离环境中模拟 KV、TCP 连接和外部数据源，不连接真实代理；通过测试不代表已验证 Cloudflare 实际部署或客户端连通性。
