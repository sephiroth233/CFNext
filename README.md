# CFNext

CFNext 是部署在 Cloudflare Workers / Pages 上的单文件代理与订阅管理面板，用于集中管理节点、优选地址和客户端订阅。当前版本：**2.0.2**。

## 功能

- 支持 VLESS / Trojan WebSocket 和 VLESS XHTTP。
- 生成常见客户端的订阅，支持预览、复制和下载。
- 管理优选 IP、域名来源、节点筛选与数量上限。
- 支持 SOCKS5、HTTP/HTTPS CONNECT 和 Shadowsocks 出站代理。
- 通过 Cloudflare KV 保存配置，支持配置导入与导出。
- 默认跟随系统主题，也可手动选择浅色或深色模式。

## 部署

仓库主脚本为 `workers.js`，无需安装项目依赖或构建。

### Cloudflare Pages

1. 创建 Pages 项目，选择直接上传。
2. 将 `workers.js` 复制为 `_worker.js`，放在上传目录或 ZIP 文件的根目录。
3. 在项目设置中配置下方的环境变量，并绑定 KV 命名空间 `K`。
4. 上传并部署；修改环境变量或绑定后，重新部署使其生效。

### Cloudflare Workers

1. 创建模块 Worker，将 `workers.js` 作为入口脚本。
2. 配置环境变量和 KV 绑定 `K`。
3. 保存并部署，使用分配的域名或已绑定的自定义域名访问。

## 配置

首次使用需配置 `U` 和 `ADMIN`；使用面板保存设置还需绑定 `K`。密码、令牌和代理凭据建议保存为 Cloudflare Secret。

| 名称 | 说明 |
| --- | --- |
| `U` | 代理 UUID，填写有效的 UUID |
| `ADMIN` | 面板管理密码，最低 8 位，建议使用至少 12 位随机密码 |
| `K` | KV 命名空间绑定名称，用于持久化面板配置 |
| `D` | 可选，自定义管理与代理路径；默认使用 UUID |
| `HOST` | 可选，订阅节点的 SNI/Host；默认使用当前访问域名 |
| `SUB_TOKEN` | 可选，独立订阅令牌，32–128 位字母、数字、下划线或连字符；未设置时由 UUID 派生 |
| `TROJAN` | 可选，设为 `true` 或 `1` 启用 Trojan |
| `TROJAN_PASSWORD` | 可选，Trojan 独立密码；留空使用 UUID |
| `S` | 可选，出站代理地址，支持 `socks5://`、`http://`、`https://`、`ss://` |
| `PROXYIP` | 可选，自定义透明中继地址，可带端口 |

其余选项可在管理面板中设置。**环境变量优先于面板保存的配置**；未绑定 KV 时，面板无法保存修改。`HOST` 只设置节点参数，自定义域名仍需在 Cloudflare 项目中绑定。

## 使用

1. 访问 `https://你的域名/login`，使用 `ADMIN` 密码登录。未登录访问根路径返回 404 属于正常行为。
2. 在面板中设置协议、优选地址和筛选条件，点击「保存全部」。
3. 回到仪表盘，选择客户端订阅格式，复制订阅链接并导入客户端。
4. 在客户端更新订阅并测试节点，按实际网络情况选择使用。

默认订阅地址为 `/s/<订阅令牌>/sub`，具体链接直接从面板复制。订阅包含连接凭据，请勿公开分享。使用 Surfboard 格式前需启用 Trojan。

右上角主题按钮按「跟随系统 → 日间 → 夜间 → 跟随系统」循环，手动偏好保存在当前浏览器。

## 使用说明

- 当前仅支持 TCP 转发，客户端 DNS 建议使用本地解析或 DoH。
- 配置保存后，不同地区可能因 KV 缓存而稍后生效。
- 配置导出不含管理密码、出站凭据等敏感字段，但仍包含 UUID 和管理路径；迁移时需重新设置未导出的凭据。
- 已登录管理面板会显示当前出站代理地址（包括其中的凭据）；清除按钮需点击「保存全部」后才生效。
- 节点可用性取决于客户端网络、数据来源与出站服务；面板测速仅供参考。
- 部署和运行受 Cloudflare 套餐限制，用量以 Cloudflare 控制台为准。
